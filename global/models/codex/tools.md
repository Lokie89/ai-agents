# 도구 목록

## 사용할 수 있는 도구

- 파일 검색: `rg`, `rg --files`
- 파일 확인: `Get-Content -Encoding UTF8`, `Select-String`, `Get-ChildItem`
- 코드 변경: `apply_patch`
- 검증: 프로젝트가 제공하는 테스트, 빌드, 린트, 타입 체크 명령
- 버전 확인: `git status`, `git diff`, `git log`
- 웹 확인: 최신 정보나 공식 문서 확인이 필요한 경우
- 병렬 읽기: 서로 독립적인 파일 확인과 검색은 가능한 경우 병렬 도구 호출로 묶는다.

## 주의해서 사용할 도구

- 패키지 설치 명령: 필요한 경우에만 실행하고 이유를 남긴다.
- 장시간 실행되는 개발 서버: 사용자가 확인할 URL이 필요할 때 실행한다.
- 자동 포맷터: 변경 범위가 넓어질 수 있으므로 대상 파일을 확인한다.
- PowerShell 명령: 파이프, 리디렉션, 와일드카드, 인코딩 기본값이 결과에 영향을 줄 수 있으므로 필요한 옵션을 명시한다.
- 웹 확인: 최신성이 중요하거나 사용자가 확인을 요청한 경우에만 사용하고, 공식 문서나 1차 출처를 우선한다.

## 금지된 도구와 행동

- 사용자 승인 없는 파괴적 명령: `git reset --hard`, `git push --force`(특히 main/master), `git clean -f`, 대량 삭제/이동
- hook 우회(`--no-verify`), 서명 우회(`--no-gpg-sign`) — 사용자가 명시적으로 요청하지 않는 한 금지
- 관련 없는 파일을 대상으로 한 자동 포맷팅
- 비밀값 출력 또는 저장
- 검증 우회를 위한 임시 코드
- 실패한 명령을 성공한 것처럼 기록하는 행위
- 단순 파일 편집을 위한 임의 스크립트 생성이나 ad hoc 파일 재작성. 수동 편집은 `apply_patch`를 우선한다.

## 도구 선택 기준

- 저장소에 이미 있는 명령과 도구를 우선 사용한다.
- 같은 결과를 낼 수 있다면 변경 범위가 작고 추적이 쉬운 도구를 선택한다.
- 네트워크나 권한 상승이 필요한 작업은 필요성과 영향을 명확히 한다.
